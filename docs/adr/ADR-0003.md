# ADR-0003: One worker and Profile per account

## Status

Accepted

## Context

XIANYU needs a stable, verifiable, auditable repository baseline before complex implementation is introduced.

## Decision

Assign one worker and one Chrome Profile to each Xianyu account.

## Consequences

- The current repository records the decision and boundary only.
- Future changes must add a new ADR to supersede a decision; historical ADRs must not be deleted.
- Unapproved implementation and dependencies must not enter the repository.
