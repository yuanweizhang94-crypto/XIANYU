# CHG-0001 Project Baseline Proposal

Status: APPROVED
Change ID: CHG-0001-project-baseline

## Summary

Establish permanent repository governance, specifications, validation scripts, tests, and CI baseline for XIANYU.

## Scope

- Root governance files.
- Project scope and architecture specifications.
- Capability registry and capability specifications.
- ADRs.
- Empty OpenAPI and JSON Schema contracts.
- Context, state generation, change validation, duplicate capability detection, unified verification, and deterministic security scan scripts.
- Tests and GitHub CI.

## Out of scope

No real Xianyu, WeCom, AI, database business, WebSocket, Playwright, FastAPI, or scheduled publishing capability is implemented.
