## Capability boundaries

- `CAP-CORE-CONFIG` owns typed settings and safe environment override behavior.
- `CAP-CORE-DATABASE` owns SQLite WAL, SQLAlchemy engine/session infrastructure, and Alembic baseline planning.
- `CAP-HEALTH-MONITOR` owns `/health`, OpenAPI health contract, and read-only runtime health reporting.

## Non-goals for this preparation commit

- No dependency installation.
- No `main.py`, `application.py`, `core/`, `api/`, `web/`, or `domain/` implementation.
- No database files or migrations.
- No `/health` implementation.
- No HTML templates.
- No external platform or AI integration.
